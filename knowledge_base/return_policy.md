# NovaCart Return Policy

## 1. Return Window and Eligibility
- Items must be returned within 30 days of the delivery confirmation date.
- Items must be in original condition: unworn, unaltered, with original packaging, warranty documentation, and UPC barcodes intact.
- Items returned between 31 and 45 days may be eligible for store credit only with a 15% restocking fee.
- Returns requested after 45 days from delivery cannot be accepted.

## 2. Return Shipping Labels
- NovaCart provides prepaid return shipping labels for all domestic returns within the continental US.
- Return shipping is completely free for damaged goods, wrong items sent, or defective hardware.
- For voluntary buyer remorse returns, a flat $5.99 return shipping fee is deducted from the final refund amount.

## 3. Drop-off and Carrier Acceptance
- Packages can be dropped off at any authorized FedEx, UPS, or NovaCart partner lockers.
- Customers must obtain a drop-off receipt showing the tracking barcode scan.
- Return processing begins immediately upon carrier scan.
